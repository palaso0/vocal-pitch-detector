# Vocal Pitch Detector

A simple web app that detects vocal pitch in real time using the user’s microphone.

## Overview

This project captures audio input and analyzes it to estimate the fundamental frequency (pitch) of the voice. It can be used for basic singing practice, pitch awareness, and audio experimentation.

All processing is done in the browser using the Web Audio API.

## Features

- Real-time pitch detection  
- Frequency output (Hz)  
- Lightweight and fast  
- Runs entirely in the browser (no backend)
